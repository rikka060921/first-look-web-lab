# 第一眼｜网站审美实验室

一个不依赖外部图片的互动学习网站。访问者可以通过六个实验，直接体验对比度、留白、视觉层级、响应反馈和用户控制如何影响信息传达，并在实时样式调试台中亲手改变一个完整页面。

## 在线预览

https://rikka060921.github.io/first-look-web-lab/

## 内容结构

1. 三秒注意力测试
2. 对比度实验
3. 留白密度实验
4. 视觉层级实验
5. 响应反馈实验
6. 用户控制实验
7. 调整前后对比
8. 实时样式调试台

## 操作方式

- 页面使用正常滚动浏览，不接管用户滚轮。
- 六个实验通过左右箭头、章节编号、键盘方向键或手机左右滑动切换。
- 每个实验均可独立操作并立即查看结果。
- 样式调试台支持标题大小、内容留白、文字对比、界面圆角与三种配色即时联动。
- 三组预设可以快速比较拥挤、平衡和海报强调的差异，调整值会保存在当前设备。
