# 第一眼｜网站审美实验室

一个不依赖外部图片的互动学习网站。访问者可以通过六个实验，直接体验对比度、留白、视觉层级、响应反馈和用户控制如何影响信息传达，并完成一份保存在本地设备的网站体检。

## 在线预览

https://rikka060921.github.io/first-look-web-lab/

## 内容结构

1. 三秒注意力测试
2. 对比度实验
3. 留白密度实验
4. 视觉层级实验
5. 响应反馈实验
6. 用户控制实验
7. 调整前后对比
8. 网站审美体检

## 操作方式

- 页面使用正常滚动浏览，不接管用户滚轮。
- 每个实验均可独立操作并立即查看结果。
- 网站体检结果保存在当前设备，可随时清空。
- 点击“打印结果”可获得适合打印或另存为 PDF 的体检页。
